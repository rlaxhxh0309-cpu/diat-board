# 디자인 콘셉트
- 밝고 건강한 느낌, 서로 응원하는 따뜻한 커뮤니티
- 모바일 화면을 먼저 생각하고 만든다

# 색상
- 메인: 민트 그린 #2BB98E (버튼, 강조)
- 포인트: 코랄 #FF7A6B (좋아요 하트, 알림)
- 배경: #F7F9F8 / 카드: 흰색
- 글자: 진한 회색 #1F2937, 보조 글자 #6B7280

# 글꼴
- Pretendard 사용, 제목은 굵게, 본문은 보통 굵기

# 모양
- 카드와 버튼 모서리 둥글게 (16px)
- 카드에 아주 옅은 그림자
- 여백은 넉넉하게

# 컴포넌트
- 사진 카드: 사진을 크게, 아래에 제목·닉네임·날짜·좋아요·댓글 수
- 버튼: 메인 버튼은 민트 배경 + 흰 글자, 보조 버튼은 흰 배경 + 민트 테두리
- 토스트 메시지: 화면 위쪽 가운데, 둥근 모서리
