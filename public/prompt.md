요청: 사이트 첫 화면에 다이어트 게시판 소개 랜딩 페이지를 만들어줘.

[페이지 구조]
- 지금 메인(/)에 있는 게시글 목록은 /board로 옮기고, 모든 링크와 이동 경로도 맞게 수정
- 새 메인(/)은 랜딩 페이지

[랜딩 페이지 구성 - 위에서 아래 순서]
1. 메인 영역: 큰 제목 "혼자 하면 힘든 다이어트, 같이 기록해요", 한 줄 설명, 
   [지금 시작하기] 버튼(회원가입으로), [게시판 구경하기] 버튼(/board로)
2. 서비스 소개: 사진으로 기록하기 / 서로 응원하기 / 내 변화 모아보기 3가지를 카드로
3. 이용 방법: 가입 → 사진 올리기 → 응원 받기 3단계
4. 최근 게시글 미리보기: 최신 사진 게시글 4~6개를 카드로 보여주고 누르면 상세 페이지로
5. 마지막 영역: "오늘부터 기록해볼까요?" + [무료로 시작하기] 버튼

[이미지]
- 사진 파일은 public/images 폴더에 있는 이미지를 사용하고, 없으면 일단 
  밝은 색 배경과 아이콘(이모지)으로 대체해줘

[공통]
- 로그인한 사용자는 [지금 시작하기] 대신 [글쓰기], [게시판 가기] 버튼 표시
- design-theme 스킬의 규칙을 따라줘
- 모바일에서도 깨지지 않게
- 메타 태그(제목, 설명, 카톡 공유 미리보기)도 랜딩 페이지에 맞게 설정
- 기존 게시판 기능은 바꾸지 마
- 답변은 한국어로 해줘
