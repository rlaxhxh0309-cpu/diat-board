요청: 개인정보 변경 페이지를 만들어줘.

[페이지]
- 상단바에 로그인한 사용자만 보이는 "내 정보" 메뉴 추가 → 개인정보 변경 페이지로 이동
- 로그인 안 한 사람은 보이지 않게 해줘

[변경 가능한 정보]
- 닉네임: 2~10자, 비어 있으면 저장 버튼 비활성화
- 프로필 사진: 업로드하면 미리보기 후 저장 (Supabase Storage profile-images 버킷, 실습용 공개)
- 비밀번호 변경: 새 비밀번호 + 비밀번호 확인 입력, 일치해야 저장 가능
  - 카카오로 가입한 사용자에게는 비밀번호 변경 영역을 숨기고 "카카오 계정으로 로그인 중이에요" 안내 표시
- 이메일은 보여주기만 하고 수정은 안 되게

[데이터베이스] Supabase MCP로 생성
- profiles 테이블: id(로그인 사용자 id와 같음, 프라이머리 키), nickname, avatar_url, updated_at
- 처음 가입한 사용자는 profiles가 없으면 자동으로 만들어줘
- RLS는 꺼줘 (실습용)
- 테이블과 버킷이 실제로 생성됐는지 확인 후 코드 작업 진행

[연동]
- 게시글, 댓글, 상단바에 이메일 대신 닉네임과 프로필 사진 표시
- 닉네임이 없으면 이메일 앞부분 표시

[공통]
- 저장 성공 시 "저장되었습니다" 토스트, 실패 시 한국어 오류 토스트
- 기존 디자인은 바꾸지 마
- 답변은 한국어로 해줘
